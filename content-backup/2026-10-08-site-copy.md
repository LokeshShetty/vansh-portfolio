# Site copy backup, 2026-10-08

Exact visible copy of www.vanshagicha.com before the product marketing
positioning pass, extracted from the production build of commit `5657226`
(live on Vercel at the time). Pages: the home page, My Videos and all six
case-study pages, in reading order. Image alt text and meta descriptions
are included.

## How to restore

The source at that point is the backup commit that adds this file, also
kept on the branch `backup/content-2026-10-08` on GitHub.

- See every change since: `git diff backup/content-2026-10-08 -- src`
- Restore all site content: `git checkout backup/content-2026-10-08 -- src`
  then commit
- Undo just the content commit: `git revert <content commit>`
